# Songscape

Songscape 是一个完全在浏览器本地运行的私人歌曲档案。它收藏的不只是歌名，也包括你为什么会一次次回到这首歌，以及与它相关的人、地点和人生片段。

V2 将收藏呈现为一间虚拟旧音像店。每首歌可以被保存为黑胶、磁带、CD 或 DVD，并通过抽出介质、打开盒体和阅读内页笔记来浏览。

## 功能

- 新增、编辑、删除歌曲，标记或取消珍藏
- 按歌名、艺人、个人感想和标签搜索
- 按标签与珍藏状态筛选
- 以独立“展品”视图阅读一首歌的完整记忆
- “Show Me Something” 从当前可见收藏中均匀随机翻出一首，并避免连续重复
- 根据每条记录的稳定种子、情绪、能量和温度生成确定性 SVG 视觉指纹
- 使用 `localStorage` 本地持久化，无需账号、后端或音乐服务
- JSON 导出与经过验证、二次确认的覆盖式导入
- 响应式布局、键盘操作、焦点样式和减少动态效果支持

## 运行

最终的 `index.html` 已内嵌全部样式和脚本，可在 Windows 或 macOS 上直接双击打开。项目也可以通过任意静态服务器运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。也可以直接打开 `index.html`，但部分浏览器会限制 `file://` 页面加载 ES Module，因此静态服务器方式更可靠。

## 数据与备份

数据保存在当前浏览器、当前站点来源的 `localStorage` 中，键名为 `songscape.collection.v1`。清理浏览器数据会删除收藏，因此长期使用前请在右上角“备份”中定期导出 JSON。

导入仅接受由 Songscape 导出的、结构正确的 JSON。通过校验后仍会要求确认，确认前不会覆盖当前收藏。

## 项目结构

- `index.html`：语义化页面、表单与对话框结构
- `styles.css`：视觉系统、响应式与无障碍样式
- `app.js`：数据规范化、存储、筛选、视觉指纹与界面协调
- `README.zh-CN.md`：中文说明
- `README.md`：English documentation

## 已知限制

- V1 仅保存封面 URL；断网时远程封面可能不可见，但视觉指纹和核心功能不受影响。
- 数据只存在当前设备和浏览器中，不会云同步。
- JSON 导入采用整库替换，不做合并；替换前会明确确认。
